# Pavan Kumar — Portfolio

Editorial personal site for Pavan Kumar, founder and brand strategist.

## Local preview

From the project root:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

Chrome launch config in `.vscode/launch.json` uses the same port.

## Edit later

- Colours, type and spacing: `css/style.css` (`:root` tokens)
- Homepage narrative: `index.html`
- Case studies: `pages/work/`
- Portrait: `assets/pavan/pavan-portrait.png`

Place project photography in the empty folders under `assets/` and reference those files from the matching sections. Do not invent client work or outcomes.
